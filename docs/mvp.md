# Web MVP 需求

## 目标

让用户在购物等场景中输入一个外币金额，立即看到该金额折算为自己熟悉币种后的数值。

## MVP 范围

- Web 端使用 Astro，适配手机与桌面浏览器。
- 主界面采用 Minecraft 风格的像素工作台视觉。
- 默认输入币种为 USD。
- 默认输入数值为 100。
- 默认本位币为 CNY。
- 用户可以修改默认输入币种。
- 用户可以保存 0–5 个本位币；保存 0 个时按 CNY 计算。
- 输入金额或修改币种后立即重新计算，不需要提交表单。
- 用户偏好保存在当前浏览器，不要求登录或跨设备同步。
- 汇率来自 `https://open.er-api.com/v6/latest/USD`，由 Web 服务端代理并放入 Workers KV。
- 汇率缓存新鲜度为 1 小时。上游故障时可以返回仍在保留期内的旧数据，但界面必须显示“缓存数据”。

## 非 MVP 范围

- Hono 独立服务端、账号、云端偏好同步。
- Expo 移动端、OCR、拍照识别价格。
- 预算、账本、历史记录、汇率提醒。
- 交易级精度、支付或投资建议。

## 验收标准

1. 新用户打开页面时，默认显示 `100 USD` 到 CNY 的换算结果；输入其他金额后结果立即更新。
2. 用户可以选择任意 API 支持的输入币种。
3. 用户最多选择 5 个目标币种，第 6 个选项不可继续添加。
4. 保存设置、刷新页面后，默认输入币种和目标币种仍然存在。
5. 在 390px 宽和常见桌面宽度下，所有控件可见、可点击且没有水平滚动。
6. 汇率 API 返回结构化错误时，页面保留金额输入并提供重试操作。
7. 键盘可以打开设置、修改控件、保存或取消；焦点样式清晰可见。
